Cruce de Figuritas

Pegá las dos listas y encontrá las figuritas que coinciden en ambas. El cruce es por código y número; cualquier emoji o texto extra tras el código se omite.

⚠️
Aviso importante: para que el sistema encuentre coincidencias con las variables FWC 🏆, FWC 🌎 y FWC 📜, es necesario escribir el número 1, 2 o 3 inmediatamente después de la letra C en ambas listas, quedando así: FWC1 🏆, FWC2 🌎 y FWC3 📜. De lo contrario, la app no podrá clasificar correctamente esas figuritas.
